このプロジェクトには `@astrojs/mdx` が導入されているため、記事の中でMarkdownとAstroコンポーネントを組み合わせられます。

## なぜMDXなのか？

MDXを使うと、読みやすく編集しやすいMarkdownを保ちながら、コンポーネントやインタラクティブな例を直接埋め込めます。

## 例

import HeaderLink from "../../../components/HeaderLink.astro";

<HeaderLink href="#" onclick="alert('clicked!')">
	MDXに埋め込まれたコンポーネント
</HeaderLink>

詳しくは [MDXドキュメント](https://mdxjs.com/docs/what-is-mdx) と [Astro MDXガイド](https://docs.astro.build/en/guides/integrations-guide/mdx/) を参照してください。
