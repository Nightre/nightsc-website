这个项目已经集成了 `@astrojs/mdx`，因此文章可以同时使用 Markdown 和 Astro 组件。

## 为什么使用 MDX？

MDX 可以让你直接在 Markdown 内容中嵌入组件和交互示例，同时保持文章容易阅读和编辑。

## 示例

import HeaderLink from "../../../components/HeaderLink.astro";

<HeaderLink href="#" onclick="alert('clicked!')">
	MDX 中嵌入的组件
</HeaderLink>

更多内容可以查看 [MDX 文档](https://mdxjs.com/docs/what-is-mdx)和 [Astro MDX 指南](https://docs.astro.build/en/guides/integrations-guide/mdx/)。
